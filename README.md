# Мовник ГО «РВН»

Для локального запуску просто відкрийте `index.html` у браузері; сервер та інтернет не потрібні. Опублікований сайт (наприклад, на GitHub Pages) працює так само, без сервера й бази даних: словник і правила РВН містяться у файлах сайту, а особистий словник винятків зберігається в браузері користувача. Словник завантажується приблизно за секунду. Обробка тексту відбувається у фоновому Web Worker.

Необов’язковий варіянт із SQLite: потрібен Node.js 22.13 або новіший. Виконайте `pnpm start` у папці проєкту й відкрийте `http://127.0.0.1:4173`. Винятки зберігатимуться у `data/rvn-exceptions.sqlite`. Сторінка звертається до цього сервера лише тоді, коли її відкрито з `localhost` або `127.0.0.1`. Сервер слухає лише цей комп’ютер й віддає тільки `index.html` і локальні файли, на які вона посилається; щоб дати доступ іншим пристроям, його треба розмістити на захищеному сервері.

## Можливості

- Відмінювані форми слів із путівника РВН, локальні винятки та милозвучність. Милозвучність враховує вже виправлене сусіднє слово: «у школу й у кімнату», «мама і в Одесі».
- Корені РВН (`ROOTS` в `engine.js`) діють у всіх відмінках, похідних і складних словах: «плян» → «плянування», «заплянувати», «генплян»; «міт» → «мітологія», «мітичний». Для кожного кореня є перелік слів, де ці літери не є коренем («планета», «вагітна», «кефір»): такі слова не змінюються. Похідні, яких путівник однозначно не визначає («планка», «планер»), і власні назви редактор лише пропонує. Автоматична заміна відбувається тільки тоді, коли стандартне написання слова є в українському словнику; тоді похідна форма РВН не вважається помилкою, хоча її самої у словнику немає.
- «Клас» і «зал» за РВН — жіночого роду («кляса», «заля»), так само злиті слова з переліку перших частин («спортзал», «майстерклас»). Форму обираємо за прийменником чи дієсловом: «до залі», «провели майстер-клясу», «Залю прикрасили». Якщо разом з іменником треба змінити узгоджені слова, редактор лише пропонує заміну всієї сполуки: «великий зал» → «велика заля», «два нові класи» → «дві нові кляси», «Зал був повний» → «Заля була повна», «Відбувся майстер-клас» → «Відбулася майстер-кляса».
- Спільні винятки в `shared-exceptions.js`: родовий «пам’яти», слово «донат», форми «приурочений» та скорочення «ім.»; вони діють без особистого словника браузера.
- Родовий відмінок після прийменників, визначених дієслів, заперечень, керівних іменників, означень та в однорідних переліках. Неоднозначні форми показуються для перевірки. Це правила контексту, а не повний синтаксичний аналізатор.
- Українська перевірка написання: Hunspell-словник dictionary-uk 4.0.0 (334979 статей та афікси) на основі VESUM. `lazy-spell.js` не розгортає наперед 3,4 млн словоформ, як nspell, а розпізнає форму під час перевірки (основа + суфікс з `.aff`). Тому словник завантажується за ~0,5 с замість ~10 с, а відповіді `correct()` і `suggest()` збігаються з nspell (перевірено на всіх формах словника). Нормативні словоформи РВН перевіряються додатково. Невідоме слово не обов’язково є помилкою.
- Оформлення пробілів, лапок, апострофів і тире; автоматичні пробіли між словом і смайликом з обох боків. URL, електронні адреси та Markdown-код захищено від замін.
- Пропозиції щодо звертань, вставних конструкцій, меж частин речення, великих літер, парних знаків, поширених випадків керування та узгодження. Покриття граматики й пунктуації обмежене описаними правилами.
- Окрема перевірка узгодження числівників із поширеними іменниками: цифри, числа словами, складені кількості, 11–14, дроби та «півтора/півтори». Для інших регулярних форм редактор пропонує заміну, якщо її підтверджує словник. Дати й очевидні відмінкові конструкції пропускаються; усі заміни потребують перегляду.
- Прийняття/відхилення окремих підказок, скасування прийнятої зміни, спільна база винятків SQLite.

## Розробка

Встановлення залежностей: `pnpm install --ignore-scripts`.

Необов’язковий запуск сервера й SQLite-бази: `pnpm start`.


Збірка: `pnpm build`. Після змін `shared-exceptions.js`, `engine.js`, `numeral-agreement.js`, `proofreader.js`, `lazy-spell.js` або `worker-entry.js` обов’язково перебудуйте `proofreading-worker.js`; сторінка виконує саме цей зібраний код. Збірка також ставить у `index.html` мітки версій за вмістом файлів (`app.js?v=…`), тому після публікації браузери завантажують нові стилі й скрипти, а не кешовані. Після будь-якої зміни `app.js` чи CSS теж запускайте `pnpm build`: тест перевіряє, що мітки відповідають файлам.

Аудит коренів: `node scripts/audit-roots.cjs [корінь ...] [--all]` показує за всім словником, які слова кожен корінь змінює, лише пропонує або пропускає. Після додавання чи зміни кореня перегляньте цей перелік і за потреби допишіть винятки (`skip`) або сумнівні слова (`review`).

Перевірки: `pnpm test` (тести запускати прямо через Node, щоб не створювати дочірні тестові процеси).

## Дані й ліцензії

- Правила РВН: наданий користувачем «Путівник основними правилами Харківського правопису» (с. 4–13).
- [dictionary-uk](https://github.com/wooorm/dictionaries/tree/main/dictionaries/uk), версія 4.0.0, на основі [VESUM / dict_uk](https://github.com/brown-uk/dict_uk). Словникові дані — GPL-3.0. Незмінні вихідні `.aff` і `.dic`, ліцензія та опис — у `vendor/`.
- [nspell](https://github.com/wooorm/nspell), версія 2.1.5, MIT; is-buffer — MIT. Тексти ліцензій — у `vendor/`.

Словник сучасної української використовується для пошуку невідомих написань; він не є повним словником історичної норми РВН. Текст не передається до зовнішніх сервісів. До локального сервера надсилається лише слово, яке користувач додає до бази винятків, а не весь текст.
